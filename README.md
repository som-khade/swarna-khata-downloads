## Install
1. Download the file on the phone.
2. Open it. If asked, allow "install from this source", then tap **Install**.
3. **On-Prem:** the app shows a *Device ID* — send it to us on WhatsApp and we will issue your licence key.
   **Cloud:** enter the site address and set-up code we send you.

The apps need a licence from Krushnai Technologies to work.
